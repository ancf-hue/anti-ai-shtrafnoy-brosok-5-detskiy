  # 🏀 ШТРАФНЫЕ·5 — 3D баскетбол для детей

> Интерактивная HTML5-игра, где нужно забросить 5 штрафных бросков и набрать больше очков, чем соперники!

![Игра ШТРАФНЫЕ·5](screenshot.png)

## 🎮 Игровой процесс

- **Цель:** Забросить 5 штрафных бросков
- **Управление:** Нажмите **ПРОБЕЛ** или **ТАПНИТЕ ПО ЭКРАНУ**, когда маркер находится в зелёной зоне
- **Результаты:** 
  - 🟢 Зелёная зона = «ЧИСТО!» (идеальное попадание)
  - 🟠 Оранжевая зона = «ЕСТЬ!» (попадание от щита)
  - 🔴 Красная зона = «МИМО!» (промах)
- **Соперники:** РЕКС и МАКС бросают параллельно с вами
- **Сложность:** Лёгкий, Средний, Сложный ×2

## ✨ Особенности

- 🎯 Реалистичная физика полёта мяча
- 🔄 Анимация пульсирующей сетки при попадании
- 🔊 Звуковые эффекты и голосовое сопровождение
- 📱 Адаптивный дизайн для ПК, планшетов и смартфонов
- 🏆 Сохранение рекордов в браузере
- 🎨 Яркая 3D-графика на Three.js

## 🚀 Как играть

1. Выберите уровень сложности (Лёгкий, Средний, Сложный ×2)
2. Нажмите **«НА СТАРТ»**
3. Дождитесь сигнала «Бросай!»
4. Следите за движущимся маркером на шкале
5. Нажмите **ПРОБЕЛ** или **ТАПНИТЕ** в зелёной зоне
6. Повторите 5 раз и узнайте результат!

## 🛠️ Технологии

- **Three.js** — 3D-движок
- **HTML5 + CSS3** — интерфейс и стили
- **Web Audio API** — звуковые эффекты
- **Speech Synthesis API** — голосовое сопровождение
- **LocalStorage** — сохранение рекордов
